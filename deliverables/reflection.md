# Week 3 reflection: vibe coding the SimWard pipeline

The most useful thing I did was write the prompt like a product manager before touching the tool. I treated my synthetic datasets as "candidates" in a hiring assistant. Requests became job postings, quality scores became evaluation criteria, and steward reviews became interviews. Then I specified the data model, the stage rules, the edge cases and the visual style in one document. Claude Code turned that into a working pipeline page in one pass, with drag and drop, a sign-off dialog and an audit log. I also asked it to test its own work in a headless browser. Those tests caught bugs I would have missed. For example, hidden screen-reader labels were making the page scroll sideways on a phone, and the last column was cut off on a laptop screen.

What frustrated me was the colour. I said the site looked "too dark", and the AI asked me a clarifying question. I chose the wrong answer, so it carefully lightened the light theme. My laptop was in dark mode, so nothing seemed to change. Finding the real cause took a second round. The AI did exactly what I said, not what I meant. Describing what I actually see, ideally with a screenshot, would have saved a cycle. The diagram showed the same pattern. Instead of asking questions, Claude listed three assumptions and went straight to drawing. The result was clean but left out my concept's Analyst agent, because my prompt never asked for it.

In my professional role, I would use these tools to make ideas concrete before asking anyone to invest in them. A clickable prototype of a data-access workflow gets better feedback from analysts and privacy staff than a written proposal. Turning a policy document into a diagram quickly shows whether everyone pictures the process the same way.

The limitations are real. My prototype stores data only in the browser and has no logins. Its "agents" return random scores within set ranges rather than running real validation. It looks finished, which can hide how far it is from production. Security, compliance, real data connections and maintenance are all still undone. The value of vibe coding is speed of learning. It does not replace engineering, and a person still has to test what the AI says it built.
